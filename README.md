# 🏫 Учёт успеваемости и посещаемости учащихся

Информационная система для автоматизации учёта успеваемости и посещаемости учащихся МАОУ ООШ №25.

## 📋 Функциональные возможности

- ✅ Авторизация пользователей с разграничением прав доступа (5 ролей)
- ✅ Управление учащимися (CRUD операции)
- ✅ Выставление и редактирование оценок
- ✅ Отметка посещаемости
- ✅ Формирование отчётов по успеваемости
- ✅ Управление пользователями (для администратора)
- ✅ Логирование всех действий
- ✅ Адаптивный дизайн
